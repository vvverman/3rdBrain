3rdBrain 1.0.0 для Mac с Apple Silicon, macOS 13.3 и новее.

1. Перетащите 3rdBrain в папку «Программы» (Applications).
2. Запустите 3rdBrain из «Программ».
3. При первом использовании разрешите доступ к микрофону.

Это личная тестовая сборка, без сертификата Developer ID и нотариального заверения Apple.
Если macOS заблокирует запуск: после первой попытки открытия зайдите в
Системные настройки → Конфиденциальность и безопасность → Всё равно открыть.
Подтверждайте исключение только для этого приложения. Не отключайте Gatekeeper.

В приложении уже находятся Java, FFmpeg, Whisper Small и Qwen3 4B.
Homebrew, Xcode и скачивание моделей после установки не требуются.
Для использования интернет не нужен. Apple Intelligence не используется.

Заметки и аудио: ~/Library/Application Support/3rdBrain
Не храните единственную копию важных записей. Для резервной копии закройте приложение
и скопируйте весь этот каталог. Обновление .app не удаляет заметки.

Веб-версия хранит данные отдельно в ~/.3rdbrain; автоматического переноса нет.
При закрытии окна незавершённое аудио сохраняется локально и может быть восстановлено
при следующем запуске. Чтобы начать новую запись, сначала восстановите предыдущую.

Эта сборка не для Intel Mac. Проверки сборки не заменяют тест физического микрофона.
