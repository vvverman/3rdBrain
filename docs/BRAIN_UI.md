# Brain UI

Brain UI — закрытый UI-слой 3rdBrain поверх Compose Foundation/UI. Цель — один стабильный набор компонентов и состояний для Android, iOS, Desktop и Web без визуальной зависимости от Material Design.

## Правило

Продуктовые экраны не создают базовые контролы напрямую. Кнопки, поля, переключатели и слайдеры берутся только из `composeApp/src/commonMain/kotlin/brain/studio/ui`.

`MaterialTheme` пока используется как контейнер наших токенов цвета и типографики. Это не разрешение использовать Material-кнопки, поля или переключатели. CI запускает `scripts/check-ui-boundary.py` и не пропускает прямые базовые контролы вне Brain UI.

## Текущий каталог

- `BrainButton` — primary/secondary, hover, pressed, focus, disabled.
- `BrainIconButton` — круглое действие с теми же состояниями.
- `BrainQuietButton` — тихое текстовое действие.
- `BrainField` — единое поле, hover/focus, явная поверхность, edit-affordance, read-only/edit mode.
- `BrainEditableNote` — единый шаблон названия + текста заметки. Используется и при создании заметки после записи, и внутри проекта.
- `BrainSwitchRow` — собственная геометрия переключателя поверх Compose interaction/semantics.
- `BrainSlider` — наш визуал и токены; зрелое поведение слайдера остаётся внутри закрытого слоя.
- `BrainPanel` — базовая поверхность.
- `BrainListCard` — интерактивная строка/карточка со состояниями hover/pressed.
- `BrainNavigationItem` — единая нижняя навигация со selected/hover/pressed/focus.
- `BrainWaveform` — звуковая волна.
- `BrainProcessingRing` — состояние обработки.
- `BrainCaptureMark` — empty-state Главной: голосовая заметка вместо декоративной ветки.

Старые имена `Action`, `IconAction`, `Editor`, `ToggleRow`, `Wave`, `ProcessingRing` временно оставлены только как совместимые прокси на Brain UI. Новые экраны должны использовать `Brain*` напрямую.

## Дизайн-правила

- никакого визуального Material/Google как источника формы;
- Onest и наши собственные иконки;
- почти монохромная палитра, тонкие границы, мягкие поверхности;
- состояния не рисуются локально на экране;
- изменение компонента должно менять его везде;
- специфические продуктовые элементы (`BrainPlayer`, `BrainProjectRow`, `BrainNoteRow`) добавляются в этот слой, а не копируются между экранами.
