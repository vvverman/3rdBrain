## Проверенные изменения

На пустой установке автоматически создаётся один проект «Твой первый проект». При повторном запуске не создаются дубликаты; существующие проекты не переименовываются. Название выбирается по текущему языку интерфейса только при создании.

Кнопка «Создать проект» доступна непосредственно на экране выбора проекта. Создание возвращает к шагу «Новая заметка / добавить в существующую» нового проекта без автоматической публикации заметки. Проверены возврат из создания и сохранность текста/аудио, ошибка создания и переход в другую вкладку во время операции.

В плеере записи квадрат «Стоп» заменён на стрелку вверх и текст «Отправить». Кнопка завершает запись и запускает обработку. При паузе записи тоже можно отправить. При прослушивании сохраняется обычная кнопка «Стоп».

## Ограничения

ИИ по-прежнему имитируется: текст не является расшифровкой голоса, веса не включены и не скачиваются. Физический микрофон, акустическое воспроизведение и разрешения на пользовательском Mac требуют пользовательского тестирования. Целевая macOS 13.3+ не означает отдельную проверку на 13.3: этот прогон выполнен на 15.7.9. Подпись ad-hoc, без Developer ID и notarization.

Данные тестовой 1.1.0 используются без изменения формата. Старые проекты не удаляются. Если у пользователя уже есть проекты, лишний стартовый проект не добавляется. Одновременные независимые веб-вкладки с записью по-прежнему не являются поддержанным сценарием; нативное приложение защищено блокировкой от второго экземпляра.
