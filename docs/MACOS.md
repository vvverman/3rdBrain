# Установка 3rdBrain для macOS

Готовая сборка 1.0.0: **Apple Silicon, macOS 13.3 и новее**. Для Intel эта сборка не подходит.

[Скачать готовый установщик](https://github.com/vvverman/3rdBrain/actions/runs/34325997689/artifacts/10094166133). GitHub скачивает ZIP; внутри находится `3rdBrain-1.0.0-macOS-arm64.dmg`. Артефакт доступен 7 дней после 9 сентября 2026.

1. Откройте DMG.
2. Перетащите 3rdBrain в Applications («Программы»).
3. Откройте 3rdBrain из «Программ» и разрешите микрофон.

Всё уже внутри: Java, аудиодвижки, Whisper Small и Qwen3-4B Q4_K_M. Homebrew, Xcode, JDK, CMake и отдельное скачивание моделей не требуются. После установки приложение работает без интернета. Это отдельное окно Compose, не браузерный ярлык.

## Первый запуск и безопасность

У личной тестовой сборки нет сертификата Developer ID и нотариального заверения Apple. Если macOS заблокирует запуск, после первой попытки откройте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Подтверждайте только это приложение. Не отключайте Gatekeeper целиком.

Если микрофон недоступен, проверьте доступ 3rdBrain в «Конфиденциальность и безопасность → Микрофон», а также выбранное устройство ввода в настройках звука.

## Данные и обновления

Заметки и аудио находятся отдельно от приложения:

`~/Library/Application Support/3rdBrain`

Замена .app не удаляет этот каталог. Для резервной копии закройте 3rdBrain и скопируйте каталог целиком. Не держите единственный экземпляр важных записей. Старое веб-хранилище `~/.3rdbrain` автоматически не переносится.

Закрытие окна останавливает приложение, а незавершённое аудио сохраняется в локальном журнале. При следующем запуске сначала восстановите эту запись через «Входящие».

## Повторная сборка для разработчика

Готовому приложению эти действия не нужны. Сборочный workflow `.github/workflows/macos.yml` можно вручную запустить через GitHub Actions. Он собирает .app на Mac arm64, вкладывает зависимости, проверяет приложение без сети и создаёт DMG. Физический микрофон и GPU на CI не подтверждаются.
