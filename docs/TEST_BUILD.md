# 3rdBrain Test 1.1.2

Тестовый вариант нового интерфейса. Модели Whisper Small и Qwen3 4B не уменьшались: их просто нет в этом установщике. Нет также скачивания весов при первом запуске.

Запись микрофона, осциллограмма, удаление длинных пауз, сохранение ускоренного аудио, проекты, заметки и настройки настоящие. Распознавание, заголовок, «Привести в порядок» и ранжирование заменены явной имитацией. Полученный текст — подготовленный пример, а не расшифровка сказанного. Это обозначено в интерфейсе, но отдельного служебного блока «Имитация ИИ» в Настройках больше нет.

Пустая установка получает проект «Твой первый проект». В выборе проекта есть «Создать проект»; после создания открывается шаг сохранения заметки в нём. При записи вместо квадрата «Стоп» показана стрелка «Отправить». Она завершает запись и запускает обработку; во время прослушивания остаётся обычный «Стоп».

Сохранённые заметки можно закреплять. Закреплённые заметки показываются первыми внутри проекта. Сохранённую текстовую заметку можно открыть, нажать «Править», изменить название и текст и сохранить. Это простой встроенный текстовый редактор без отдельного формата документа; связанные аудиоисточники при правке текста не изменяются.

Без микрофона доступна кнопка «Попробовать без микрофона»: создаёт тестовый звуковой сигнал и проводит его через тот же путь обработки аудио и сохранения. Тестовый текст фиксированный; отдельного выбора служебных примеров в Настройках нет.

Откройте DMG, перетащите «3rdBrain Test» в Applications, откройте приложение и при необходимости разрешите микрофон. Java и FFmpeg уже внутри, Homebrew/Xcode/JDK не требуются. Сборка предназначена для Apple Silicon, целевая macOS 13.3+. Проверка на конкретном микрофоне пользователя выполняется отдельно.

У тестовой сборки ad-hoc подпись, без Developer ID и notarization. При блокировке неизвестного разработчика используйте стандартное подтверждение только этого приложения в «Конфиденциальность и безопасность». Не отключайте Gatekeeper целиком.

Данные изолированы от старой версии: `~/Library/Application Support/3rdBrain Test`. Старое приложение и его записи не меняются. Отдельного списка входящих и пользовательских черновиков нет: восстанавливается одна текущая запись. Следующую можно начать после сохранения текущей в проект или её удаления. После закрытия приложение не продолжает записывать скрытно.

По умолчанию: автозапись включена (с учётом разрешения микрофона), автопереход к проекту выключен, экономное аудио, сохранение 1,5×, системные язык и тема. Скорость плеера 1× означает обычное воспроизведение уже ускоренного сохранённого файла. Настройки качества/темпа применяются к новым записям и не перекодируют старые источники.

Восемь языков относятся к интерфейсу, не к гарантированному качеству распознавания. В этой сборке распознавания нет.
