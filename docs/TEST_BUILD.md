# Kasha Test 1.1.4

Тестовый вариант нового интерфейса. Модели Whisper Small и Qwen3 4B не уменьшались: их просто нет в этом установщике. Нет также скачивания весов при первом запуске.

Запись микрофона, осциллограмма, удаление длинных пауз, сохранение ускоренного аудио, проекты, заметки и настройки настоящие. Распознавание, заголовок, «Привести в порядок» и ранжирование заменены явной имитацией. Полученный текст — подготовленный пример, а не расшифровка сказанного. Это обозначено в интерфейсе, но отдельного служебного блока «Имитация ИИ» в Настройках нет.

В 1.1.4 начат собственный закрытый слой **Brain UI** поверх Compose: кнопки, поля, переключатели, панели, строки списков, навигация, waveform и состояния теперь задаются централизованно. Продуктовые экраны не должны создавать базовые Material-контролы напрямую; это проверяется в CI. MaterialTheme остаётся только контейнером наших токенов, а внешний вид контролов задаёт Brain UI.

Редактор новой заметки после обработки и редактор сохранённой заметки используют один компонент. Название и текст теперь явно выглядят как поля: есть подписи, поверхность, граница, состояния hover/focus и пиктограмма редактирования. В просмотре сохранённой заметки те же поверхности можно нажать, чтобы перейти к правке.

На пустой Главной убрана декоративная «ветка». Вместо неё используется понятная монохромная иллюстрация голосовой заметки: лист, запись, waveform и строки текста.

Пустая установка получает проект «Твой первый проект». В выборе проекта есть «Создать проект»; после создания открывается шаг сохранения заметки в нём. При записи вместо квадрата «Стоп» показана стрелка «Отправить». Она завершает запись и запускает обработку; во время прослушивания остаётся обычный «Стоп».

Сохранённые заметки можно закреплять. Закреплённые заметки показываются первыми внутри проекта. При ручной правке текста связанные аудиоисточники не изменяются.

Без микрофона доступна кнопка «Попробовать без микрофона»: создаёт тестовый звуковой сигнал и проводит его через тот же путь обработки аудио и сохранения. Тестовый текст фиксированный; отдельного выбора служебных примеров в Настройках нет.

Откройте DMG, перетащите «Kasha Test» в Applications, откройте приложение и при необходимости разрешите микрофон. Java и FFmpeg уже внутри, Homebrew/Xcode/JDK не требуются. Сборка предназначена для Apple Silicon, целевая macOS 13.3+. Проверка на конкретном микрофоне пользователя выполняется отдельно.

У тестовой сборки ad-hoc подпись, без Developer ID и notarization. При блокировке неизвестного разработчика используйте стандартное подтверждение только этого приложения в «Конфиденциальность и безопасность». Не отключайте Gatekeeper целиком.

Данные изолированы от старой полной версии: `~/Library/Application Support/Kasha Test`. Обновление тестовой версии использует тот же каталог и не удаляет существующие тестовые проекты/заметки. Отдельного списка входящих и пользовательских черновиков нет: восстанавливается одна текущая запись. Следующую можно начать после сохранения текущей в проект или её удаления.

По умолчанию: автозапись включена (с учётом разрешения микрофона), автопереход к проекту выключен, экономное аудио, сохранение 1,5×, системные язык и тема. Скорость плеера 1× означает обычное воспроизведение уже ускоренного сохранённого файла. Настройки качества/темпа применяются к новым записям и не перекодируют старые источники.

Восемь языков относятся к интерфейсу, не к гарантированному качеству распознавания. В этой сборке распознавания нет.

## Переименование

В 1.1.4 продукт называется **Kasha**. Тестовое macOS-приложение — **Kasha Test**, данные — `~/Library/Application Support/Kasha Test`, bundle ID — `ru.vrmn.kasha.test`. Служебные переменные окружения используют префикс `KASHA_`.
