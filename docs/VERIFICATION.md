# Проверки Kotlin-версии

Идёт проверка новой реализации. Предыдущие 71 Swift-тест относятся к удалённой Swift-версии и не являются подтверждением Kotlin-приложения.

Состав: shared — правила и обработка данных; composeApp — общие состояния интерфейса; runtime — диск, HTTP-защита, подпроцессы и реальный FFmpeg на синтетическом сигнале. Отдельно собирается production WebAssembly.

Вызов настоящих весов Whisper/LLM и нативные мобильные клиенты пока не проверены. Итоговые результаты фиксируются только после исполнения, не по наличию файлов тестов.
