# Русский язык: сначала проверяем Apple

Актуальное решение владельца от 8 сентября 2026 года: «попробуем на эппле всё сделать, там посмотрим, не будет русского переделаем».

Это решение заменяет предыдущий план подключения Whisper. В текущей сборке только системное распознавание Apple и Foundation Models. Не добавляем сторонние модели до проверки на реальном iPhone. Реализация Whisper сохранена в истории Git до этого изменения; зависимости, интерфейс загрузки и автоматическое переключение на Whisper из текущей версии исключены.

## Что проверять отдельно

**Речь → текст:** `SpeechTranscriber` и `DictationTranscriber`. Приложение получает поддерживаемые и установленные локали с устройства. Установленный локальный модуль имеет приоритет над незагруженным. Дополнительные ресурсы Apple загружаются только после подтверждения. Отмена не запускает запасной модуль.

**Оформление текста и ранжирование проектов:** `Foundation Models`. Проверяются `availability` и `supportsLocale`. Нет статически зашитого списка запрещённых языков. Если API не поддерживает русский или модель недоступна, приложение показывает причину, оставляя транскрипт и ручную работу. Whisper эту текстовую задачу не заменяет.

## Проверка на телефоне

В настройках есть подготовка русской речевой модели, отдельные статусы двух подсистем, проверка ИИ-оформления на небольшом примере и отправка диагностики. Полный сценарий: [APPLE_DEVICE_CHECK.md](APPLE_DEVICE_CHECK.md).

Наличие API, автоматические тесты выбора локалей и успешная сборка не доказывают качество русского на конкретном iPhone. Решение о замене принимается по результатам реальной записи и проверки текста, а не по предположениям.

Первоисточники Apple: [SpeechAnalyzer и DictationTranscriber](https://developer.apple.com/videos/play/wwdc2025/277/), [Foundation Models и языки](https://developer.apple.com/documentation/foundationmodels/supporting-languages-and-locales-with-foundation-models).
