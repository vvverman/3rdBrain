# 3rdBrain — текущий этап Kotlin / Web

Решение владельца: Swift удаляется, приложение переносится на Kotlin Multiplatform и Compose Multiplatform. Сначала тестируем веб, затем добавляем iOS/Android/macOS. Максимально один код. Десктоп выглядит как мобильное приложение, без отдельной адаптации; ширина до 430 dp.

## Сценарий

После первоначального согласия — попытка автозаписи при открытии. Постоянная нижняя панель: состояние, таймер, пауза/продолжить, завершить. Просмотр проектов и заметок не прерывает запись. Отказ микрофона не блокирует работу с текстами. Завершение не запускает новую запись немедленно.

Источник сохраняется до обработки. Оригинал, полная транскрипция, обработанный текст и компактное аудио — отдельные сущности/представления. Длинные паузы сокращаются, сохраняется карта времени; ускорение воспроизведения не меняет оригинал. Ошибка модели не удаляет запись. Необработанные записи остаются во входящих.

## Организация

Проект → заметки. Поля проекта: название, описание, «Что сюда складывать», закрепление и ручной порядок закреплённых. Все проекты показываются при выборе: закреплённые сверху, затем незакреплённые по релевантности локальной LLM. Без успешного ранжирования — обычная сортировка с явной пометкой. Проект выбирает пользователь.

После проекта — все его заметки и «Новая заметка». Выбор существующей добавляет новый текст только в конец, не меняет старый текст и сохраняет собственный аудиоисточник добавления. Повторное сохранение не создаёт дубликат.

## Локальный веб

Первый веб-клиент общается с локальным Kotlin/Ktor-процессом на 127.0.0.1:8787. Хранение — файловый адаптер компьютера. Whisper и LLM запускаются локально, без Apple Speech/Foundation Models и внешних облачных API. Модели устанавливаются отдельно. Браузерное аудио временно журналируется в IndexedDB до подтверждения дискового сохранения.

UI и правила в commonMain; платформенные адаптеры не меняют общий сценарий. Нативные цели и распространение приложений — следующий этап. Ограничения фоновой записи браузера не скрываются.

## Не включать

Автосоздание проектов, автоматическое распределение, подбор похожих заметок моделью, интеллектуальное переписывание существующих заметок, вложенные папки, iCloud, совместную работу, отдельный десктопный UI.
