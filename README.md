# 3rdBrain — локальные голосовые заметки

**Открыл → сказал → выбрал проект → новая заметка или добавление в конец существующей.**

Kotlin Multiplatform и Compose Multiplatform. Все продуктовые экраны и правила общие. На компьютере тот же мобильный интерфейс шириной до 430 dp, без отдельной десктопной раскладки.

## Готовое приложение для Mac

**3rdBrain 1.0.0 для Apple Silicon, macOS 13.3+.** [Скачать установщик](https://github.com/vvverman/3rdBrain/actions/runs/34325997689/artifacts/10094166133). GitHub скачивает ZIP с готовым DMG; артефакт хранится 7 дней после 9 сентября 2026.

Откройте DMG, перетащите 3rdBrain в Applications и запустите. Внутри уже находятся Java, FFmpeg, Whisper Small и Qwen3-4B Q4_K_M. Ничего отдельно устанавливать или загружать после установки не нужно. Размер установщика около 3,06 ГБ; модели не уменьшены и не заменены.

Личная тестовая сборка имеет ad-hoc подпись, без Developer ID и нотариального заверения Apple. На первом запуске может потребоваться подтверждение через «Конфиденциальность и безопасность → Всё равно открыть» и разрешение микрофона. Отключать защиту macOS не нужно.

[Подробности установки и хранения данных](docs/MACOS.md). [Результаты проверки](docs/VERIFICATION.md).

## Возможности

Постоянная панель записи, пауза и продолжение, входящие, проекты с полем «Что сюда складывать», закрепления с ручным порядком, ручной выбор проекта из полного списка с ИИ-сортировкой. После проекта выбирается новая или существующая заметка. Добавление не переписывает старый текст и сохраняет собственные источники.

Оригинальное аудио, полный транскрипт и подготовленный текст сохраняются отдельно. Длинные паузы сокращаются в дополнительной аудиоверсии; ускоренное воспроизведение не меняет оригинал. Ошибка модели не удаляет запись.

## Общий код и платформы

- `shared/commonMain`: модели данных, правила, сортировка, обработка таймкодов и текста, запросы к LLM и проверка ответов.
- `composeApp/commonMain`: все экраны и состояние интерфейса.
- `composeApp/wasmJsMain`: веб-адаптеры HTTP, микрофона, IndexedDB и HTMLAudio.
- `runtime`: Kotlin/JVM, дисковый адаптер, запуск моделей и Ktor-сервис для веб-клиента.
- `desktopApp`: macOS-клиент, нативные аудиоадаптеры, восстановление WAV-журнала, прямой доступ к общему хранилищу и упаковка .app/DMG. Для обычного нативного запуска HTTP-сервис не нужен.

iOS и Android пока не собраны. Swift/Xcode-прототип удалён из актуального дерева, но остаётся в истории Git.

## Локальные данные

Приложение macOS: `~/Library/Application Support/3rdBrain`.

Веб-сервис: `~/.3rdbrain`, либо каталог `THIRDBRAIN_HOME`. Автоматического переноса из веб-версии нет. Для резервной копии остановите приложение и скопируйте каталог целиком. Это файловый адаптер, без iCloud и синхронизации.

## Веб-версия для разработки и тестирования

Следующие инструменты нужны только при запуске исходников, не пользователю готового DMG.

С установленной JDK 21:

```bash
bash run-web.sh
```

Открыть `http://127.0.0.1:8787`. Для запуска без пересборки: `bash run-web.sh --no-build`.

Это локальный веб-интерфейс с сервисом на компьютере, не облачный сайт. Сервис слушает 127.0.0.1; публично выставлять его нельзя. Без настроенных моделей можно записывать аудио и работать с текстами вручную. Для голосового сценария:

```bash
bash scripts/setup-models.sh
bash run-web.sh
```

Скрипт подготовки использует CMake/компилятор и скачивает модели в `~/.3rdbrain-tools`; пути затем подхватываются `run-web.sh`. Существующий файл `Запустить 3rdBrain.command` — старый запуск веб-версии из исходников, **не установщик нового .app**. [Подробности конфигурации моделей](docs/LOCAL_MODELS.md).

Браузер журналирует аудио в IndexedDB до подтверждения дискового сохранения. Очистка браузерных данных до передачи может удалить несохранённый источник. Одновременная запись в двух вкладках не поддерживается, фоновая запись при выгрузке вкладки не гарантирована.

## Проверки

```bash
bash scripts/gradle.sh :shared:jvmTest :composeApp:jvmTest :runtime:test :desktopApp:test :composeApp:wasmJsBrowserDistribution
```

Аудиотестам исходников нужен FFmpeg. Проверенный DMG прошёл отдельный запуск со встроенной Java и моделями при запрещённой сети, открытие окна, проверку целостности и подписи. Нативный интеграционный тест использовал CPU виртуального Mac и синтезированную русскую речь; физический микрофон, акустическое воспроизведение и GPU пользовательского устройства не проверялись. Подробности и точные границы — в [VERIFICATION.md](docs/VERIFICATION.md).
