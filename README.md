# 3rdBrain — локальные голосовые заметки

**Записать → отправить на обработку → исправить текст → выбрать проект → новая заметка или дополнение существующей.**

## Готовая тестовая версия для Mac

**3rdBrain Test 1.1.1 — 142,3 МБ, Apple Silicon, целевая macOS 13.3+.**

[Скачать ZIP с готовым DMG](https://github.com/vvverman/3rdBrain/actions/runs/34464474930/artifacts/10146994433). Внутри `3rdBrain-Test-1.1.1-macOS-arm64.dmg` и контрольная сумма. Артефакт доступен до 10 октября 2026 года.

Закройте предыдущую тестовую версию, откройте DMG и перетащите **3rdBrain Test** в «Программы», подтвердив замену приложения. Java, FFmpeg и ресурсы интерфейса уже внутри. Homebrew, Xcode и отдельная установка JDK не нужны. Данные тестовой версии находятся вне .app и при замене не удаляются.

### Изменения 1.1.1

- Если проектов ещё нет, при запуске создаётся **«Твой первый проект»**. В него можно сразу сохранить первую заметку. Повторный запуск не создаёт дубликатов. Существующие проекты и их названия не меняются.
- На экране выбора проекта есть **«Создать проект»**. После создания открывается шаг сохранения заметки в созданный проект. Возврат из редактора сохраняет текущие текст и аудио.
- Во время записи и её паузы вместо квадрата «Стоп» показана стрелка **«Отправить»** с подписью. Она завершает запись и запускает обработку, но не сохраняет заметку в проект без выбора пользователя. При прослушивании остаётся обычная остановка.

## Тест без моделей

**ИИ намеренно имитируется.** Весов Whisper Small и Qwen3 4B в пакете нет, при запуске они не скачиваются. После записи появляется подготовленный тестовый текст, **не расшифровка вашего голоса**. Имитация обозначена на экране. Реальными остаются запись микрофона, осциллограмма, обработка и воспроизведение аудио, редактирование текста, проекты и сохранение.

На Главной запишите короткое аудио или используйте «Попробовать без микрофона». После обработки исправьте текст, при необходимости нажмите «Привести в порядок», затем «Отправить в проект». Выберите готовый первый проект или создайте собственный прямо здесь. Далее — «Новая заметка» или дополнение существующей.

По умолчанию автозапись включена с учётом разрешения микрофона. Для теста без микрофона отключите «Начать запись при включении» и отправьте либо отмените уже начавшуюся запись. В настройках имитации доступны три примера: идея приложения, учебный пароль, рецепт.

## Интерфейс и данные

Один мобильный интерфейс на Kotlin Multiplatform / Compose, шириной до 430 dp. Светлая и тёмная темы, системная тема по умолчанию. Встроенный Onest и собственные векторные пиктограммы. Восемь языков интерфейса: русский, английский, испанский, французский, немецкий, украинский, белорусский, казахский; по умолчанию язык системы. Первый проект получает название на языке интерфейса при создании; последующая смена языка его не переименовывает.

На Главной одна текущая запись, без входящих и черновиков. Плеер и нижняя навигация всегда видны. Навигация не прерывает запись. Прослушивание другого источника требует подтверждения остановки записи. Все сохранённые заметки принадлежат проектам.

Аудио сохраняется без длинных пауз, с выбранными качеством и темпом. По умолчанию экономное качество и сохранение 1,5× без изменения высоты голоса. Временный исходник удаляется после проверки итогового файла. Скорость плеера 1× относится к уже обработанному файлу.

Данные: `~/Library/Application Support/3rdBrain Test`, тот же каталог, что у тестовой 1.1.0, отдельно от полной версии 1.0.0. Аккаунта, iCloud и синхронизации нет. Сборка ad-hoc подписана, без Developer ID и нотариального заверения Apple. Микрофон требует разрешения системы.

## Проверки

Программный коммит **`630c95ff2bbddd2962333c5d0dc1707ae6452cbf`**. В отчётах macOS/Linux **90 уникальных тестов Kotlin**, без ошибок и пропусков; часть неизменённых задач использовала кеш. Дополнительно успешно пройдены браузерный путь с реальными кликами и синтетическим микрофоном, запуск упакованного .app без сети со встроенной Java/FFmpeg, проверка подписи и DMG. Новые сценарии первого проекта, создания проекта из выбора и кнопки отправки включены в проверки.

[Проверки 1.1.1](docs/VERIFICATION_1_1_1.md) · [Актуальное ТЗ](docs/SPEC.md) · [Особенности тестовой версии](docs/TEST_BUILD.md) · [Историческая проверка 1.1.0](docs/VERIFICATION.md).

Физический микрофон и акустическое воспроизведение на пользовательском Mac не подтверждены автоматическими тестами. Нативная проверка выполнена на виртуальном macOS 15.7.9 arm64. Тестовая версия не проверяет качество распознавания и настоящей LLM. iOS и Android пока не собраны.

## Разработка

Общие правила — `shared/commonMain`, экраны и состояние — `composeApp/commonMain/kotlin/brain/studio`, macOS-аудиоадаптеры и упаковка — `desktopApp`. Web использует те же экраны с браузерными адаптерами и локальным Ktor-сервисом.

`studio.yml` собирает облегчённый DMG; `kotlin.yml` проверяет общее ядро и браузер. Onest подготавливается `scripts/prepare-fonts.py` только при сборке. Web-тест запускает сервис с `THIRDBRAIN_DEMO_AI=1`. Выбранные модели будут возвращены в полную поставку после тестирования интерфейса.
