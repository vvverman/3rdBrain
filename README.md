# 3rdBrain — Kotlin, сначала веб

Локальный голосовой блокнот: **открыл → сказал → выбрал проект → новая заметка или добавление в конец существующей**.

Один мобильный интерфейс Compose в `commonMain`. На широком мониторе та же колонка шириной до 430 dp, без боковых панелей и отдельной десктопной раскладки. Swift/Xcode удалены из актуального дерева; старый код остаётся в истории Git.

## Запуск на Mac

Открыть **`Запустить 3rdBrain.command`** из папки репозитория. При необходимости — из терминала:

```bash
bash 'Запустить 3rdBrain.command'
```

Первый запуск устанавливает недостающие CMake, FFmpeg и JDK 21 через уже установленный Homebrew, собирает закреплённые движки, загружает Whisper Small и Qwen3 4B (около 3 ГБ весов суммарно), проверяет SHA-256 и открывает приложение в браузере. Homebrew самостоятельно не устанавливается. Для сборки C++ нужны Command Line Tools; полный Xcode не обязателен. Уже скачанные корректные модели повторно не загружаются; они хранятся вне репозитория, в `~/.3rdbrain-tools`.

Файл запуска не обновляет Git автоматически и не удаляет ваши изменения. Перед обновлением остановите предыдущий запуск через Ctrl+C в его окне терминала. Получите новый код командой `git pull --ff-only`, затем снова запустите приложение.

## Только интерфейс / запуск на Linux

Нужна **JDK 21**. Из папки клонированного репозитория:

```bash
bash run-web.sh
```

Скрипт загрузит закреплённый Gradle 8.14.5 с проверкой SHA-256, соберёт веб и локальный сервис. Затем открыть **http://127.0.0.1:8787**. Для следующего запуска без пересборки: `bash run-web.sh --no-build`. Интернет нужен для первоначальной загрузки инструментов и зависимостей.

Это веб-интерфейс **с локальным сервисом на вашем компьютере**, а не облачный сайт и не исполнение моделей внутри вкладки. Сервис слушает только 127.0.0.1. Публично выставлять его в сеть нельзя. Для тестирования только интерфейса Xcode, Android Studio и платный аккаунт не нужны.

Без моделей можно записывать и слушать аудио, создавать проекты, вводить текст вручную, раскладывать записи и добавлять их в конец заметок. Отсутствующая модель не заменяется фиктивным результатом.

## Полный голосовой сценарий

Автоматическая подготовка моделей (также используется запускным файлом Mac):

```bash
bash scripts/setup-models.sh
bash run-web.sh
```

Если все четыре переменные `THIRDBRAIN_WHISPER_*` / `THIRDBRAIN_LLAMA_*` не заданы, `run-web.sh` сам читает подготовленные пути из `~/.3rdbrain-tools/models.env`. Другой каталог инструментов можно задать через `THIRDBRAIN_TOOLS_HOME`.

Для собственного набора установите FFmpeg, подготовьте `whisper-cli`, `llama-completion`, многоязычную модель Whisper (не `.en`) и совместимую русскоязычную модель GGUF. Задайте существующие локальные пути:

```bash
export THIRDBRAIN_WHISPER_CLI=/полный/путь/whisper-cli
export THIRDBRAIN_WHISPER_MODEL=/полный/путь/ggml-small.bin
export THIRDBRAIN_LLAMA_CLI=/полный/путь/llama-completion
export THIRDBRAIN_LLAMA_MODEL=/полный/путь/model.gguf
# Необязательно, по умолчанию ffmpeg из PATH:
export THIRDBRAIN_FFMPEG=/полный/путь/ffmpeg
bash run-web.sh
```

Без вызова скрипта первоначальной настройки веса не скачиваются. Нужен однократный режим `llama-completion --single-turn`, не интерактивный чат. Подготовленный набор использует закреплённые версии движков; альтернативные веса могут потребовать иных параметров. Несовместимый или непрошедший проверки ответ оставляет исходный транскрипт. Качество на вашей живой речи нужно проверить отдельно.

Подробнее о моделях, проверках и ограничениях: [docs/LOCAL_MODELS.md](docs/LOCAL_MODELS.md).

## Что общее между платформами

- `shared/commonMain`: модели данных, правила заметок, идемпотентное добавление, закрепления, сортировка, нарезка текста, план сокращения пауз, запросы к LLM и проверка результатов.
- `composeApp/commonMain`: все экраны и состояния приложения. Один мобильный UI.
- `composeApp/wasmJsMain`: браузерный запуск, HTTP, микрофон и воспроизведение. Небольшой `browser-platform.js` — только адаптер MediaRecorder/IndexedDB/HTMLAudio, не второй интерфейс.
- `runtime`: Kotlin/JVM + Ktor, дисковый адаптер и запуск локальных моделей для веб-тестирования.

Нативные приложения пока **не собраны**. Следующий этап для них — платформенные адаптеры хранилища, записи и исполнения моделей, а не переписывание экранов. JVM-цель `composeApp` сейчас служит для проверки общего UI-кода, не является готовым desktop-приложением.

## Данные и безопасность

Данные: `~/.3rdbrain/brain.json` и `~/.3rdbrain/audio`, либо каталог `THIRDBRAIN_HOME`. JSON публикуется атомарно до обновления состояния в памяти. Для резервной копии остановить сервис и скопировать весь каталог. Это простой файловый адаптер, не SQLite и не синхронизация.

Браузер сохраняет фрагменты записи в IndexedDB; при сбое передачи доступна повторная отправка, в том числе после перезагрузки страницы. Удаление браузерных данных до успешной передачи может уничтожить несохранённый источник. Не открывайте две вкладки с одновременной записью. Веб не гарантирует запись при блокировке телефона или выгрузке вкладки системой.

Для первой записи нужно разрешение микрофона. Автостарт после согласия зависит от разрешений браузера; есть ручная кнопка. Оригинал не удаляется автоматически. Сокращение пауз консервативное, не полноценный речевой детектор; оригинал сохраняется для проверки. Полный транскрипт отделён от текста LLM; источники всех добавлений доступны из заметки.

## Тестирование

```bash
bash scripts/gradle.sh :shared:jvmTest :composeApp:jvmTest :runtime:test :composeApp:wasmJsBrowserDistribution
```

Отдельный workflow `models.yml` проверяет настоящие Whisper и Qwen на синтезированной русской речи, в Linux network namespace без внешней сети. Его можно запустить вручную через GitHub Actions. Piper применяется только для создания тестовой речи и не входит в приложение. Это не оценка качества живого микрофона.

Аудиотестам нужен FFmpeg. Актуальные результаты — [docs/VERIFICATION.md](docs/VERIFICATION.md). Старые Swift-тесты не относятся к Kotlin-версии.
