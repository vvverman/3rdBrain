# 3rdBrain — Kotlin, сначала веб

Локальный голосовой блокнот: **открыл → сказал → выбрал проект → новая заметка или добавление в конец существующей**.

Один мобильный интерфейс Compose в `commonMain`. На широком мониторе та же колонка шириной до 430 dp, без боковых панелей и отдельной десктопной раскладки. Swift/Xcode удалены из актуального дерева, старый код остаётся в истории Git.

## Запуск на Mac / Linux

Нужна **JDK 21**. Из папки клонированного репозитория:

```bash
bash run-web.sh
```

Скрипт загрузит закреплённый Gradle 8.14.5 с проверкой SHA-256, соберёт веб и локальный сервис. Затем открыть **http://127.0.0.1:8787**. Для следующего запуска без пересборки: `bash run-web.sh --no-build`. Интернет нужен для первоначальной загрузки инструментов и зависимостей. Сами заметки и аудио не уходят в облако.

Это веб-интерфейс **с локальным сервисом на вашем компьютере**, а не облачный сайт и не исполнение моделей внутри вкладки. Сервис слушает только 127.0.0.1. Публично выставлять его в сеть нельзя. Для тестирования интерфейса Xcode, Android Studio и платный аккаунт не нужны.

Без моделей уже можно записывать и слушать аудио, создавать проекты, вводить текст вручную, раскладывать записи и добавлять их в конец заметок. Автоматическая транскрипция и оформление потребуют моделей ниже. Отсутствующая модель не заменяется фиктивным результатом.

## Полный голосовой сценарий

Установить FFmpeg, собрать/установить `whisper-cli` из whisper.cpp и `llama-completion` из llama.cpp. Подготовить многоязычную модель Whisper (не `.en`) и русскоязычную instruct-модель GGUF. Задать **существующие локальные пути**, затем запустить приложение в том же терминале:

```bash
export THIRDBRAIN_WHISPER_CLI=/полный/путь/whisper-cli
export THIRDBRAIN_WHISPER_MODEL=/полный/путь/ggml-small.bin
export THIRDBRAIN_LLAMA_CLI=/полный/путь/llama-completion
export THIRDBRAIN_LLAMA_MODEL=/полный/путь/instruct-model.gguf
# Необязательно, по умолчанию ffmpeg из PATH:
export THIRDBRAIN_FFMPEG=/полный/путь/ffmpeg
bash run-web.sh
```

Веса не скачиваются автоматически. Название поля `_LLAMA_CLI` сохранено, но нужен однократный режим `llama-completion --single-turn`, а не интерактивный чат. Модель должна выполнять инструкции и возвращать JSON; несовместимый ответ оставляет исходный транскрипт, а не переписывает его. Совместимость конкретных весов и качество русского требуют проверки на ваших записях.

## Что общее между платформами

- `shared/commonMain`: модели, правила заметок, идемпотентное добавление, закрепления, сортировка, нарезка текста, план сокращения пауз и разбор результатов моделей.
- `composeApp/commonMain`: все экраны и состояния приложения. Один мобильный UI.
- `composeApp/wasmJsMain`: браузерный запуск, HTTP, микрофон и воспроизведение. Небольшой `browser-platform.js` — только адаптер MediaRecorder/IndexedDB/HTMLAudio, не второй интерфейс.
- `runtime`: Kotlin/JVM + Ktor, дисковый адаптер и запуск локальных моделей для веб-тестирования.

Нативные приложения пока **не собраны**. Их следующий этап — платформенные адаптеры хранилища, записи и исполнения моделей, а не переписывание экранов. JVM-цель `composeApp` сейчас служит для проверки общего UI-кода, не является готовым desktop-приложением.

## Данные и безопасность

Данные: `~/.3rdbrain/brain.json` и `~/.3rdbrain/audio`, либо каталог `THIRDBRAIN_HOME`. JSON публикуется атомарно до обновления состояния в памяти. Для резервной копии остановить сервис и скопировать весь каталог. Это пока простой файловый адаптер, не SQLite и не синхронизация.

Браузер сохраняет фрагменты записи в IndexedDB; при сбое передачи доступна повторная отправка, в том числе после перезагрузки страницы. Удаление браузерных данных до успешной передачи может уничтожить несохранённый источник. Не открывайте две вкладки с одновременной записью. Веб не гарантирует запись при блокировке телефона или выгрузке вкладки системой.

Для первой записи нужно разрешение микрофона. Автостарт после согласия зависит от разрешений браузера; есть ручная кнопка. Оригинал не удаляется автоматически. Сокращение пауз консервативное, не полноценный речевой детектор; оригинал сохраняется для проверки. Полный транскрипт отделён от текста LLM; источники всех добавлений доступны из заметки.

## Тестирование

```bash
bash scripts/gradle.sh :shared:jvmTest :composeApp:jvmTest :runtime:test :composeApp:wasmJsBrowserDistribution
```

Аудиотестам нужен FFmpeg. Актуальный статус — [docs/VERIFICATION.md](docs/VERIFICATION.md). Старые Swift-тесты не относятся к Kotlin-версии.
