# Kasha — локальные голосовые заметки

**Записать → отправить на обработку → исправить текст → выбрать проект → новая заметка или дополнение существующей.**

## Тестовая версия для Mac

**Kasha Test 1.1.4 — Apple Silicon, целевая macOS 13.3+.**

Тестовый пакет не содержит весов Whisper Small и Qwen3 4B: они не уменьшены и не заменены другими моделями, а просто исключены из этой сборки. Реальными остаются микрофон, waveform, обработка и сохранение аудио, плеер, проекты, заметки, редактор, закрепления и настройки. Распознавание и LLM-действия в тестовой версии явно имитируются.

### Что изменилось в 1.1.4

- Продукт переименован в **Kasha** во всём исходном коде, интерфейсе, упаковке, web-адаптере, переменных окружения, bundle ID, локальном хранилище и документации.
- macOS-приложение: `Kasha`; тестовый пакет: `Kasha Test`.
- bundle ID: `ru.vrmn.kasha` / `ru.vrmn.kasha.test`.
- данные тестовой сборки: `~/Library/Application Support/Kasha Test`.
- web storage и служебные переменные используют префикс `kasha` / `KASHA_`.
- CI отдельно проверяет, что прежнее имя больше не встречается ни в содержимом репозитория, ни в именах файлов.

Сохраняется Brain UI: один закрытый слой компонентов поверх Compose Foundation/UI. Экран новой заметки после записи и редактор сохранённой заметки используют один `BrainEditableNote`, а пустая Главная показывает смысловую графику голосовой заметки вместо декоративной ветки.

## Интерфейс и данные

Один мобильный интерфейс на Kotlin Multiplatform / Compose, шириной до 430 dp. Светлая и тёмная темы, Onest, собственные пиктограммы. Восемь языков интерфейса: русский, английский, испанский, французский, немецкий, украинский, белорусский, казахский.

На Главной одна текущая запись. Плеер и нижняя навигация всегда видны. Навигация не прерывает запись. Все сохранённые заметки принадлежат проектам. Аудио сохраняется без длинных пауз, с выбранными качеством и темпом.

## Разработка

Общие правила — `shared/commonMain`, экраны и состояние — `composeApp/commonMain/kotlin/brain/studio`, macOS-аудиоадаптеры и упаковка — `desktopApp`. Web использует те же экраны с браузерными адаптерами и локальным Ktor-сервисом.
