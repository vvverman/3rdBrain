## Готовая тестовая версия для Mac

**3rdBrain Test 1.1.0 — 142,3 МБ, Apple Silicon, целевая macOS 13.3+.**

[Скачать ZIP с готовым DMG](https://github.com/vvverman/3rdBrain/actions/runs/34460819119/artifacts/10145551842). Артефакт GitHub доступен до 10 октября 2026 года. Внутри `3rdBrain-Test-1.1.0-macOS-arm64.dmg` и контрольная сумма.

Откройте DMG, перетащите **3rdBrain Test** в «Программы» и запустите. Java, FFmpeg, интерфейсные ресурсы уже внутри; Homebrew, Xcode, JDK и отдельные установки не нужны. Это самостоятельное окно приложения, не браузерный ярлык.

**В этой версии ИИ намеренно имитируется.** Весов Whisper Small и Qwen3 4B нет, при запуске они не скачиваются. Модели не заменены уменьшенными. После записи появляется подготовленный тестовый текст, **не расшифровка вашего голоса**. Имитация явно отмечена на экране. Реальными остаются запись микрофона, осциллограмма, обработка и воспроизведение аудио, редактирование текста, проекты и сохранение.

### Как пройти весь путь

Создайте проект в разделе «Проекты». Вернитесь на «Главную» и запишите короткое аудио либо нажмите **«Попробовать без микрофона»**. После обработки отредактируйте тестовый текст, при необходимости нажмите «Привести в порядок», затем «Отправить в проект». Выберите проект и новую заметку либо заметку для добавления текста в конец.

По умолчанию автозапись включена с учётом разрешения микрофона. Чтобы тестировать без записи голоса, отключите «Начать запись при включении» и завершите уже начавшуюся запись. В настройках имитации доступны три примера: идея приложения, учебный пароль, рецепт.

## Интерфейс и поведение

Один мобильный интерфейс на Kotlin Multiplatform / Compose, шириной до 430 dp. Светлая и тёмная темы, системная тема по умолчанию. Встроенный Onest и собственные векторные пиктограммы. Восемь языков интерфейса: русский, английский, испанский, французский, немецкий, украинский, белорусский, казахский; по умолчанию язык системы.

На Главной одна текущая запись, без списка входящих и черновиков. Плеер и нижняя навигация всегда видны. Навигация не прерывает запись. Попытка прослушать другой источник во время записи требует подтверждения остановки. Сохранённые заметки принадлежат проектам.

Аудио сохраняется без длинных пауз, с выбранными качеством и темпом. По умолчанию экономное качество и сохранение 1,5× с сохранением высоты голоса. Исходник удаляется только после проверки итогового файла. Скорость плеера 1× означает обычное воспроизведение уже обработанного файла. Текущий текст восстанавливается после перезапуска.

## Установка и данные

Сборка ad-hoc подписана, но не имеет Developer ID и нотариального заверения Apple. При предупреждении о неизвестном разработчике после попытки запуска используйте стандартное подтверждение **только этого приложения** в «Конфиденциальность и безопасность». Защиту macOS целиком отключать не нужно. Микрофон требует отдельного разрешения.

Тестовое приложение хранит данные в `~/Library/Application Support/3rdBrain Test`, отдельно от версии 1.0.0. Старое приложение и его записи не перезаписываются. Автоматического переноса данных, аккаунта, iCloud и синхронизации нет. Перед ручной резервной копией закройте приложение и скопируйте каталог целиком.

## Разработка

Общие правила находятся в `shared/commonMain`, экраны и состояния — в `composeApp/commonMain/kotlin/brain/studio`. `desktopApp` содержит macOS-аудиоадаптеры и упаковку. Web использует те же экраны, с браузерными адаптерами и локальным Ktor-сервисом. iOS и Android пока не собраны.

Сборочный workflow `studio.yml` создаёт облегчённый DMG; `kotlin.yml` проверяет общее ядро и браузер. Ресурсы Onest подготавливаются `scripts/prepare-fonts.py` только при сборке; готовому приложению это не нужно. Веб-тест запускает сервис с `THIRDBRAIN_DEMO_AI=1`. В производственную поставку веса выбранных моделей будут возвращаться отдельно после проверки интерфейса.
